# CHEZ ATEH

Boutique e-commerce mode et puériculture inspirée de la marque CHEZ ATEH, spécialisée dans les vêtements, chaussures, accessoires et produits pour bébé/famille à Abidjan.

## Aperçu

Ce projet est une boutique en ligne statique dédiée à la vente de produits pour enfants, adultes et puériculture, avec :
- navigation par catégories
- promos et offres
- carrousel de produits
- sections avis clients
- boutons WhatsApp / commandes
- design premium mobile-first / desktop

## Fichiers principaux

- `index.html` : structure HTML complète du site
- `README.md` : documentation du projet

## Lancer le projet localement

1. Ouvrir le fichier `index.html` dans le navigateur, ou
2. servir le dossier avec un petit serveur local :

```bash
python -m http.server 8000
```

Puis ouvrir :

```text
http://localhost:8000
```
